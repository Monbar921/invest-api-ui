# Тестирование invest-api-ui

```bash
npm test               # Vitest, один прогон
npm run lint           # ESLint
npm run typecheck      # tsc без сборки
npm run format:check   # Prettier
```

Vitest с окружением jsdom, глобальные `describe/it/expect`, настройка - `src/test/setup.ts`
(подключает `@testing-library/jest-dom`, заглушки `matchMedia`, `ResizeObserver` и `scrollIntoView`, которых нет в jsdom). `src/test/render.tsx` рендерит страницу внутри Mantine, TanStack Query, `SessionContext` (по умолчанию вошедший
пользователь `USER`, гостя - `session: GUEST`) и memory-роутера, а отдельный компонент - только внутри Mantine. `mockFetch` отдаёт ответы по порядку вызовов, а на
попутные запросы ленты, обзора рынка, событий и подборок отвечает пустыми данными сам; `mockFetchByUrl` - ответы по шаблону URL. `src/test/analytics.ts`: `enableAnalytics()` включает счётчик и согласие и подменяет `window.ym`, `sentGoals` / `sentHits` - что ушло в счётчик; после каждого теста `setup.ts` возвращает сборку без счётчика. Тесты лежат рядом с кодом: `*.test.ts(x)`.

## CI

`.github/workflows/ci.yml` на push и PR в master/develop/uat: `npm ci` → `format:check` → `lint` → `test` → `build`.
Любой шаг валит сборку, поэтому перед коммитом стоит прогнать `npm run format`.
