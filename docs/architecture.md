# Архитектура invest-api-ui

SPA для [invest-api](../../invest-api/): таблица облигаций с фильтрами и карточка облигации с графиком купонных выплат.

Стек: React 19 + TypeScript, Vite, Mantine 9 (`mantine-datatable` - таблица, `@mantine/charts` - график),
TanStack Query - запросы и кэш, React Router - маршруты.

```
браузер ──▶ UI ──(same origin)──▶ invest-gateway ──▶ invest-api
                                       └── Keycloak (логин)
```

## Структура `src/`

| Папка / файл                         | Что                                                                                    |
| ------------------------------------ | -------------------------------------------------------------------------------------- |
| `api/client.ts`                      | `fetch`-обёртка: same-origin cookie, CSRF-заголовок, 401 → логин, ошибки ProblemDetail |
| `api/bonds.ts`                       | запросы к `/api/bonds/...`                                                             |
| `api/queries.ts`                     | хуки TanStack Query (`useBondsPage`, `useBond`)                                        |
| `api/types.ts`                       | типы ответов, вручную повторяют DTO из `invest-api-dto`                                |
| `pages/`                             | `BondsPage`, `BondPage`, `NotFoundPage`                                                |
| `components/`                        | таблица, фильтры, график выплат, бейдж риска, состояние ошибки                         |
| `layout/`                            | `AppLayout`: шапка, тема, выход                                                        |
| `lib/`                               | состояние таблицы в URL (`bondSearchParams`), форматирование денег, дат, риска         |
| `router.tsx`, `theme.ts`, `main.tsx` | маршруты, тема Mantine, точка входа                                                    |

## Экраны

- `/bonds` - облигации: вкладки «Все / Рублёвые / Валютные» (`all` / `local` / `foreign` на бэке), фильтры по цене
  в рублях и в % от номинала, риску, ОФЗ и типу купона (постоянный / переменный), сортировка по колонкам, серверная пагинация. Колонки
  «К погашению, % год.» (сортировка `YIELD_TO_MATURITY`) и «К оферте, % год.» (сортировка `YIELD_TO_OFFER`,
  под значением дата оферты); «—», если оферты нет или бэк не смог посчитать доходность (например, флоатер).
- `/bonds/:ticker` - карточка: цена, номинал (с отметкой об амортизации), НКД, купон, доходность к погашению
  (в подсказке - доходность к оферте и дата оферты), погашение, ближайшая выплата и график выплат.

## API

| Запрос                                                   | Что                                             |
| -------------------------------------------------------- | ----------------------------------------------- |
| `POST /api/bonds/{all\|local\|foreign}/page?page=&size=` | страница облигаций, в теле фильтры и сортировка |
| `GET /api/bonds/{ticker}`                                | облигация с графиком выплат                     |

Пути относительные: UI и gateway на одном origin (в dev - через Vite proxy, на стенде - через ingress), иначе
session cookie и `XSRF-TOKEN` не работают. `VITE_API_URL` нужен, только если API на другом адресе.

Типы в `api/types.ts` синхронизируются с `invest-api-dto` руками: новое поле в DTO нужно добавить и сюда.
Доходности к погашению и к оферте (invest-api INVEST-001) в UI пока не выведены.

## Авторизация

- Ответ `401` - сессии на gateway нет: `client.ts` уходит на `/oauth2/authorization/keycloak`, после входа gateway
  вернёт обратно.
- Изменяющие запросы (не GET/HEAD/OPTIONS) отправляют значение cookie `XSRF-TOKEN` в заголовке `X-XSRF-TOKEN`.
- Выход - `POST /logout`, gateway отвечает `202` с адресом выхода из Keycloak в `Location`, UI переходит туда.

## Состояние таблицы в URL

Вся выборка хранится в query-строке (`lib/bondSearchParams.ts`): ссылку можно сохранить, «Назад» работает.

| Параметр                   | Что                                  | По умолчанию |
| -------------------------- | ------------------------------------ | ------------ |
| `scope`                    | `all` / `local` / `foreign`          | `all`        |
| `page`                     | номер страницы с 1 (бэк считает с 0) | 1            |
| `size`                     | 25 / 50 / 100 / 200                  | 50           |
| `sort`                     | `ПОЛЕ:ASC\|DESC`                     | `PRICE:ASC`  |
| `priceMin`, `priceMax`     | цена в рублях                        | -            |
| `percentMin`, `percentMax` | цена в % от номинала                 | -            |
| `risk`                     | уровни риска через запятую           | все          |
| `ofz`                      | `any` / `only` / `exclude`           | `any`        |
| `coupon`                   | `any` / `fixed` / `floating`         | `any`        |

В URL пишутся только значения, отличные от умолчаний. Неизвестные значения при разборе заменяются умолчаниями.
Сортировка в UI - по одному полю; бэк поддерживает несколько.
