# invest-api-ui

UI для [invest-api](https://github.com/Monbar921/invest-api): таблица облигаций с фильтрами и карточка облигации
с графиком купонных выплат. React 19 + TypeScript, Vite, Mantine 9, TanStack Query.

```bash
npm install
npm run dev       # http://localhost:5173, нужны запущенные invest-gateway (с Keycloak) и invest-api
```

Документация - в [docs/](docs/README.md): архитектура, тесты, запуск и деплой.
